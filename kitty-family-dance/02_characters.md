# Kitty Family Dance — 캐릭터 디자인

공통 스타일은 저장소 루트의 `STYLE_GUIDE.md`를 따릅니다.

**캐릭터 선정 근거:** 고양이는 미취학 인기 IP Gabby's Dollhouse의 중심 캐릭터이고 아이들에게 가장 친숙한 반려동물 중 하나. 판다와 달리 가족마다 털 색을 다르게 줄 수 있어 Veo에서 캐릭터가 섞이지 않음.

**키 비교:** Mochi 1 : Grandma 1.5 : Mommy 2.1 : Daddy 2.6 — **털 색 + 소품 색**으로 구분합니다 (주황 / 흰색 / 연회색 / 먹회색).

## Mochi

> 털실만 보면 폴짝 뛰어드는 막내 아기 고양이. 가족 중 가장 작고 가장 동그람.

| 항목 | 설정 |
|---|---|
| 성격 | 호기심 많고 장난꾸러기. 움직이는 건 일단 쫓아감 |
| 형태 언어 | 원(머리) + 콩 모양 몸통 + 뾰족하지 않게 둥근 삼각 귀 |
| 비율 | 1.7등신. 두 발로 섬. 가족 중 가장 작음 |
| 얼굴 | 아주 큰 동그란 파란 눈(홍채 크게, 하이라이트 2개), 작은 분홍 코, 크림색 주둥이, 이마에 옅은 크림 줄무늬 3개 |
| 컬러 | 털 주황 `#F2A65A` · 줄무늬·주둥이·배 크림 `#FCE8CF` · 눈 파랑 `#5BA4E6` · 목걸이 분홍 `#F49AC1` · 방울 금색 `#E9B949` |
| 시그니처 | **Pounce Wiggle**: 납작 웅크려 엉덩이 씰룩 → 앞발 쫙 펴고 폴짝. 움직일 때마다 방울 딸랑 |
| 표정 | 털실 보고 눈 동그래짐, 폴짝 직전 집중한 눈, 함박웃음, 화면에 묻는 갸웃, 와! 놀람, 장난기 곁눈질 |
| 움직임 | 통통 튀는 걸음. 폴짝 착지 때 몸이 눌렸다 펴짐 |
| 목소리 | 아주 높은 3살 여자아이 목소리, 키득 웃음 많음 |
| 일관성 체크 | 분홍 방울 목걸이 항상. 가족 중 항상 가장 작게. 주황 털(흰 고양이·노란 고양이로 바뀌지 않게) |

## Mommy Cat

> 꼬리와 리본을 휘날리며 빙글빙글 도는 우아한 엄마.

| 항목 | 설정 |
|---|---|
| 성격 | 다정하고 우아함. 가족 율동의 리더 |
| 형태 언어 | 부드러운 S자 곡선, 날씬한 서양배 모양 |
| 비율 | 3등신. 가족 중 가장 날씬 |
| 얼굴 | 긴 속눈썹, 아몬드형 연두빛 눈, 흰 주둥이, 부드러운 미소 |
| 컬러 | 털 연회색 `#BFC3CC` · 가슴·주둥이 흰색 `#FFFFFF` · 눈 연두 `#B5CC5A` · 리본 라벤더 `#B9A7E0` |
| 시그니처 | 까치발로 빙글 두 바퀴, 꼬리가 나선을 그림 |
| 표정 | 우아한 미소, 빙글 돌며 눈 감은 행복, 놀란 Wow |
| 움직임 | 까치발로 사뿐사뿐. 돌 때 꼬리와 리본이 한 박자 늦게 따라옴 |
| 목소리 | 따뜻하고 노래하는 듯한 젊은 엄마 목소리 |
| 일관성 체크 | 라벤더 리본은 항상 한쪽 귀에. 아빠보다 작고 할머니보다 크게 |

## Daddy Cat

> 쿵쿵 점프로 소파 쿠션까지 튀게 만드는 흥 많은 아빠.

| 항목 | 설정 |
|---|---|
| 성격 | 유쾌하고 장난기 많음. 큰 덩치로 몸개그 |
| 형태 언어 | 큰 원 두 개(머리 + 배). 넓고 묵직 |
| 비율 | 3.5등신. 가족 중 가장 큼 |
| 얼굴 | 웃을 때 눈이 초승달로 감김, 흰 주둥이, 큰 입, 통통한 볼 |
| 컬러 | 털 먹회색 `#4A4752` · 가슴·주둥이·발 흰색 `#FFFFFF` · 눈 초록 `#5FBF7A` · 나비넥타이 빨강 `#E5484D` |
| 시그니처 | 제자리 점프 3번, 착지마다 쿵 하고 쿠션이 튐. 끝나면 나비넥타이 고쳐 매기 |
| 표정 | 눈 감고 크게 웃기, 자신만만 윙크 없이 씩 웃기, 놀란 Wow |
| 움직임 | 묵직하게 쿵쿵, 착지 때 배가 출렁 |
| 목소리 | 낮고 굵은 유쾌한 아빠 목소리 |
| 일관성 체크 | 빨간 나비넥타이 항상. 가족 중 항상 가장 크게. 흰 가슴·흰 발 유지 |

## Grandma Cat

> 느릿느릿 기지개를 켜다가 갑자기 번개처럼 거실을 도는 반전 할머니.

| 항목 | 설정 |
|---|---|
| 성격 | 느긋하고 다정하지만 숨은 실력자. 입버릇 "Oh my!" |
| 형태 언어 | 작은 원 + 풍성한 털로 더 동그래 보임 |
| 비율 | 2.5등신. Mochi보다 크고 엄마보다 작음 |
| 얼굴 | 동그란 보라 안경 너머 작은 눈, 눈가 주름, 은빛 수염 몇 가닥 |
| 컬러 | 털 흰색 `#FAF7F2` · 안경 보라 `#8C6BC8` · 숄 민트 `#9ED9C2` |
| 시그니처 | 느린 기지개 4번 → 갑자기 번개 같은 질주 한 바퀴 |
| 표정 | 인자한 미소, 기지개 켜며 눈 감음, 질주 후 뿌듯한 "Oh my!" |
| 움직임 | 평소엔 아주 느리게, 질주만 번개처럼 빠르게(대비가 개그) |
| 목소리 | 따뜻하고 살짝 떨리는 할머니 목소리 |
| 일관성 체크 | 보라 안경과 민트 숄 항상. 털이 길고 풍성한 흰색 |
