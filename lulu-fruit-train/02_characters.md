# Lulu's Fruit Train — 캐릭터 디자인

공통 스타일은 저장소 루트의 `STYLE_GUIDE.md`를 따릅니다.

**캐릭터 선정 근거:** 토끼는 2026 그림책 등장 동물 2위, 인기 인형 목록 단골. 당근 좋아하는 토끼라 채소 먹기 메시지와 바로 연결됨.

**키 비교:** Lulu 1 (귀 제외) : Chuggy 기관차 1.4 (Lulu가 기관차 칸에 쏙 들어가는 크기)

## Lulu

> 작은 몸으로 기차를 모는 꼬마 기관사 토끼. 한쪽만 접힌 귀가 실루엣 포인트.

| 항목 | 설정 |
|---|---|
| 성격 | 씩씩하고 책임감 있음. 당근은 최고, 브로콜리는 살짝 망설이지만 결국 도전 |
| 형태 언어 | 원 + 긴 귀 두 개(오른쪽은 쫑긋, 왼쪽은 접힘). 솜꼬리도 원 |
| 비율 | 2등신(귀 제외). 귀까지 포함하면 머리 높이의 2배 |
| 얼굴 | 큰 초록 눈(홍채 크게, 하이라이트 2개, 속눈썹 3가닥), 하얀 주둥이, 분홍 Y자 코, 앞니 두 개가 살짝 보이는 미소, 발그레한 볼 |
| 컬러 | 털 피치크림 `#F6D5B8` · 주둥이·배 흰색 `#FFF8F0` · 귀 안쪽 분홍 `#F4B5C4` · 눈 초록 `#5FBF7A` · 기관사 모자 파랑·흰 줄무늬 `#3E7CC9` · 반다나 빨강 `#E5484D` |
| 시그니처 | **Hop Hop Toot**: 깡충깡충 두 번 + 두 손 모아 "Toot toot!". 기분 좋으면 접힌 귀가 잠깐 쫑긋 |
| 표정 | 기관사 결의, 딸기 잡고 함박웃음, 브로콜리 앞에서 망설임, 한 입 먹고 눈 반짝, 화면에 묻는 갸웃, 당근 먹으며 볼 빵빵 |
| 움직임 | 걸을 때도 살짝살짝 깡충. 착지할 때 squash & stretch |
| 목소리 | 또랑또랑한 여자아이 목소리 |
| 일관성 체크 | 왼쪽 귀는 항상 접힘. 모자는 두 귀 사이에. 빨간 반다나 유지. 털은 피치크림(흰 토끼로 바뀌지 않게) |

## Chuggy

> 장난감 같은 작은 증기기관차. 신나면 굴뚝에서 과일이 팝콘처럼 튐.

| 항목 | 설정 |
|---|---|
| 성격 | 명랑한 수다쟁이. 출발할 때마다 "All aboard!" |
| 형태 언어 | 땅딸막한 둥근 원통 + 둥근 바퀴. 모서리 전부 둥글게 |
| 비율 | 기관차 1칸(뒤쪽에 Lulu가 타는 작은 운전석) + 나무 화물칸 3칸. 기관차 높이는 Lulu의 약 1.4배 |
| 얼굴 | 보일러 앞면에 큰 둥근 눈 두 개와 웃는 입, 볼 대신 빨간 램프 |
| 컬러 | 기관차 빨강 `#E8483B` · 굴뚝 노랑 `#FFC93C` · 화물칸 나무 `#C98B55` · 바퀴 남색 `#2F3E66` |
| 시그니처 | "TOOT!" 하면 굴뚝에서 과일 팝콘 |
| 표정 | 활짝 웃음, 놀라서 동그란 눈, 달릴 때 신난 얼굴 |
| 움직임 | 달릴 때 몸통이 통통 튀는 장난감 같은 움직임 |
| 목소리 | 명랑하고 살짝 쉰 아저씨 목소리 |
| 일관성 체크 | 팔 없음. 화물칸은 항상 3칸. 장면에 기차는 하나만 |
