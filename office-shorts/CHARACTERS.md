# 고정 등장인물 (실사풍 AI 배우)

주인공 김대리는 **실제 고양이**, 팀장과 신입은 실사 사람입니다. 동료들이 고양이에게 아무렇지 않게 일을 맡기는 부조리 자체가 개그입니다.

| | 김대리 | 박팀장 | 이도윤 |
|---|---|---|---|
| 역할 | 주인공 (고양이) | 빌런 | 아래에서 치고 올라오는 사람 |
| 성별·나이 | 실제 크기 성묘 고양이 | 남성, 46세 | 남성, 25세 |
| 한눈에 보이는 표식 | 샴 포인트 무늬 + 파란 눈 + 오른쪽 앞발 흰 발끝 + 검정 사원증 | 댄디컷 + 네이비 니트 조끼 + 딸깍 볼펜 | 투블럭 웨이브 머리 + 세이지그린 맨투맨 + 흰 무선 이어폰 |
| 메인 색 | 아이보리 크림 + 초콜릿 브라운 | 하늘색 + 네이비 | 세이지그린 |

## 김대리 — 주인공 (실제 고양이)

| 항목 | 설정 |
|---|---|
| 정체 | 실제 크기의 성묘 고양이. 의인화하지 않음 (두 발로 서지 않고 옷도 안 입음) |
| 직급 | IT 회사 디자인팀 3년 차 대리 |
| 한 줄 | 도도하고 시크한데 회사 사람들은 아무렇지 않게 일을 맡기는 고양이. 겉으로는 성실하게 "냥", 속으로는 다 말함 |
| 외형 | 날렵하고 늘씬한 체형, 목이 길고 다리가 곧음. 샴 고양이 포인트 무늬(아이보리 크림 몸통, 얼굴 마스크·귀·발·꼬리는 초콜릿 브라운), 작은 역삼각형 얼굴, 크고 뾰족한 귀 |
| 얼굴·표식 | 아몬드형 **사파이어 블루 눈**(눈꼬리 살짝 올라감), 평소엔 눈을 반쯤 내리깔고 턱을 든 시크한 표정. **오른쪽 앞발 발끝만 흰색** (키보드 위 발로 알아봄, 매 편 고정) |
| 소품 | 목에 작은 **검정 사원증 줄 + 흰 사원증** (매 편 고정). 그 외 옷·액세서리 없음 |
| 자리 | 사무 의자 위 방석, 앞발은 키보드 옆. 모니터 앞에서 식빵 자세 |
| 겉말 | 고양이 울음소리나 몸짓 + 흰 자막. 예: 짧은 "냥" + 자막 "네! 물론이죠!" |
| 속마음 | 낮고 건조한 성인 목소리 내레이션 + 노란 자막 |
| 시그니처 | 일을 받으면 회사용 동그란 눈 → 돌아서자마자 눈을 내리깔고 턱을 듦. 꼬리를 앞발에 감고 꼿꼿하게 앉아 모니터 응시 |

## 박팀장 (박상철) — 겉은 호감, 속은 빌런

| 항목 | 설정 |
|---|---|
| 나이·직급 | 46세, 디자인팀 팀장 |
| 한 줄 | 처음 보면 좋은 상사 같은데, 순식간에 돌변해 폭언과 인격 모독을 퍼붓는 사람 |
| 성격 | 남들 앞에서는 다정하고 젠틀함. 단둘이 있거나 일이 틀어지면 폭언·인격 모독. 윗사람 앞에서는 다시 공손해짐 |
| 외형 | **빌런 티가 전혀 안 나는 호감형.** 177cm 슬림, 부드러운 얼굴선, 순한 눈매, 웃으면 눈가 잔주름. 안경 없음 |
| 머리 | 앞머리를 내려 오른쪽으로 살짝 넘긴 깔끔한 댄디컷, 귀 옆에 흰머리 몇 가닥 |
| 옷 | 하늘색 옥스퍼드 셔츠(넥타이 없음) + **네이비 브이넥 니트 조끼** + 베이지 치노 + 갈색 로퍼, 검정 사원증 줄 |
| 소품 | **은색 노크식 볼펜**을 늘 오른손에 쥐고 엄지로 딸깍 (매 편 고정). 딸깍 소리가 돌변 직전 신호 |
| 말투 | 평소엔 부드러운 존댓말. 돌변하면 반말과 폭언 |
| 연출 | 외모가 아니라 **다정한 미소 → 싸늘한 무표정**으로 바뀌는 순간이 충격 포인트 |

## 이도윤 — MZ 신입

| 항목 | 설정 |
|---|---|
| 나이·직급 | 25세, 입사 6개월 차 사원 |
| 한 줄 | 김대리가 속으로만 하는 말을 겉으로 해 버리는 사람 |
| 성격 | 무표정하지만 예의 바름. 정각 6시 퇴근, 할 말은 담백하게. 일은 의외로 잘함 |
| 얼굴 | 갸름한 얼굴, 무심한 눈빛, 무표정이 기본 |
| 머리 | **검은 투블럭 웨이브** 머리 (앞머리가 눈썹을 살짝 덮음) |
| 옷 | **세이지그린 맨투맨** + 검은 와이드 슬랙스 + 흰 운동화 |
| 소품 | 오른쪽 귀에 **흰 무선 이어폰 한쪽** (매 편 고정) |
| 말투 | 담백하고 짧게. "저 먼저 들어가 보겠습니다~", "그건 업무 범위가 아닌 것 같은데요?" |
| 시그니처 | 6시 정각 알람과 동시에 일어나기. 김대리는 그걸 보며 "멋있다…" |

## 관계

```
박팀장 ──일 던짐──▶ 김대리 ◀──대리만족── 이도윤
   ▲                                      │
   └──────── 담백하게 거절 ◀───────────────┘
```

- 김대리 ↔ 박팀장: 겉말 vs 속마음 정면충돌. 다정한 얼굴로 다가와 폭언으로 돌변하는 충격
- 김대리 ↔ 이도윤: 세대 차이. 도윤이 대신 말해 주면 김대리 속마음 "멋있다…"
- 박팀장 ↔ 이도윤: 팀장이 도윤에게는 이상하게 일을 못 던짐 → 김대리에게 몰림 (반복 개그)

## 실사풍 얼굴 유지 규칙

실사 AI는 장면마다 얼굴이 바뀌는 게 가장 큰 문제라 아래를 지킵니다.

1. **레퍼런스 2장씩:** 얼굴(정면·3/4·측면 상반신)과 전신 의상 정면. Veo 재료로는 전신 정면 1장을 씁니다.
2. **표식은 절대 안 바꿈:** 집게핀·금테 안경 / 회색 조끼·텀블러 / 맨투맨·이어폰. 옷을 갈아입는 에피소드는 만들지 않습니다.
3. **프롬프트마다 같은 묘사 문장을 그대로 복사**해서 넣습니다.
4. **실존 인물과 닮지 않게:** 레퍼런스 프롬프트에 "an original fictional person, not resembling any real celebrity"를 넣었습니다. 생성 결과가 특정 연예인을 닮았으면 다시 만듭니다.
5. **AI 표시:** 업로드할 때 플랫폼의 AI 생성 콘텐츠 표시를 반드시 켭니다.
