# 에피소드 아이템 (1차 10개)

모두 "누구나 한 번은 겪은 순간" + 겉말/속마음 어긋남 + 반전 구조입니다. 등장인물은 편당 2명 이내.

| # | 제목 (훅 자막) | 등장 | 펀치 / 반전 | 장소 | PPL 자리 |
|---|---|---|---|---|---|
| 01 | 퇴근 5분 전, 가장 무서운 말 | 김대리, 박팀장 | "잠깐 시간 돼?" → 일 폭탄 → "농담이야" → 팀장도 상무 전화에 영혼 탈출 | 사무실 | 책상 위 커피 |
| 02 | "자유롭게 의견 내 보세요" | 김대리, 박팀장 | 아이디어 냈더니 "그럼 김대리가 맡아" → 다음 회의에서 아무도 입을 안 엶 | 회의실 | 회의실 간식 |
| 03 | 점심 뭐 먹을래? "아무거나" | 김대리, 박팀장 | 메뉴 5개 다 거절 → 결국 어제 먹은 곳 | 사무실 → 엘리베이터 | 배달 앱 화면 |
| 04 | 엘리베이터에 대표님과 단둘이 | 김대리 | 12층이 120층처럼 느껴짐 (층수 표시 슬로 연출) → 내리자마자 숨 몰아쉬기 | 엘리베이터 | 없음 |
| 05 | 월요일 "주말 잘 보냈어?" | 김대리, 이도윤 | 김대리 겉말 "네~ 푹 쉬었죠" / 속마음 회상 컷: 주말 내내 누워 있음. 도윤은 담백하게 "저는 제주도 다녀왔습니다" | 탕비실 | 커피 머신, 간식 |
| 06 | 정각 6시, 신입의 한마디 | 김대리, 이도윤 | 도윤 "먼저 들어가 보겠습니다~" → 김대리 속마음 "멋있다…" → 따라 일어나려다 팀장과 눈 마주침 | 사무실 | 도윤의 이어폰 |
| 07 | "확인 부탁드립니다" 읽씹 | 김대리 | 메신저 숫자 1이 사라졌는데 답이 없음 → 5분마다 확인 → 답장 "ㅇㅇ" | 사무실 | 휴대폰 |
| 08 | 월급날 | 김대리 | 입금 알림 → 카드값·월세 알림이 연달아 → 잔고 스치듯 사라짐 | 사무실 | 가계부·은행 앱 화면 |
| 09 | 연차 쓰겠다고 말하는 법 | 김대리, 박팀장 | 머릿속 리허설 10번 → 막상 팀장 "응 쉬어~" 한마디 → 허탈 | 사무실 | 여행 앱 화면 |
| 10 | 회식 2차 탈출 작전 | 김대리, 이도윤 | 첩보 영화처럼 탈출 시도 → 도윤은 이미 "저 먼저 갑니다~" 하고 정문으로 당당히 퇴장 | 엘리베이터 | 택시 앱 화면 |

## 올리는 순서

1. **01, 06, 08**을 먼저 올립니다. 설명 없이 누구나 바로 아는 상황이라 공유가 잘 됩니다.
2. 반응(댓글 수, 저장, 공유)이 가장 좋은 인물을 다음 편에 더 자주 등장시킵니다.
3. 댓글에서 나온 사연으로 11화부터 만듭니다 ("여러분 회사는 어때요?"가 아이템 수집 장치).
