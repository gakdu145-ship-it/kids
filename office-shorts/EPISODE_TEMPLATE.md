# 에피소드 대본 템플릿

`episodes/epNN/script.md`로 복사해 씁니다. 컷 하나 = Veo 클립 하나(8초) → 편집에서 2~3컷으로 나눠 씁니다.

```markdown
# EP NN. 제목

**훅 자막:** (0~3초에 화면 위에 뜨는 한 줄, 15자 이내)
**등장:** 김대리, ○○ (2명 이내)
**장소:** 사무실 / 회의실 / 탕비실 / 엘리베이터
**길이 목표:** 30~40초
**PPL 자리:** (쌓기 구간에 둘 물건 하나)
**댓글 유도:** (마지막 자막 질문)

| 컷 | 시간 | 화면 | 겉말 (화면 대사) | 속마음 (내레이션) | 자막 | 효과음 |
|---|---|---|---|---|---|---|
| 1 | 0~3 | | | | 훅 자막 | |
| 2 | 3~8 | | | | | |
| ... | | | | | | |

## Veo 생성 컷

| 클립 | 쓰는 컷 | 재료 이미지 | 대사 넣을지 |
|---|---|---|---|
| clip1 | 컷 1~2 | kim, office | 없음 (속마음만) |
```

## 쓰는 규칙

- **겉말**은 Veo `Dialogue:`에 한국어로 넣습니다. 한 줄 15자 이내.
- **속마음**은 Veo에 넣지 않습니다. 편집에서 김대리 내레이션 + 노란 자막.
- 반전은 최소 1번, 가능하면 2번 (팀장도 당하는 2차 반전 등).
- 마지막 자막은 질문 형태로 끝내 댓글을 받습니다.
- 클립 프롬프트는 `Camera / Setting / Characters / Action / Dialogue / Audio / Style` 순서. Style 줄 끝에 항상 `not photorealistic, no subtitles, no text, no background music`.
