# Panda Family Roll — 캐릭터 디자인

공통 스타일은 저장소 루트의 `STYLE_GUIDE.md`를 따릅니다.

**키 비교:** Bao 1 : Grandma 1.6 : Mommy 2.2 : Daddy 2.8 — 판다는 모두 흑백이라 **크기 + 소품 색**으로 구분합니다.

## Bao

> 공처럼 굴러다니는 막내 판다. 가족 중 가장 작고 가장 동그람.

| 항목 | 설정 |
|---|---|
| 성격 | 호기심 많고 장난꾸러기. 무엇이든 굴러서 해결 |
| 형태 언어 | 완벽한 원. 앉으면 털뭉치 공 |
| 비율 | 1.6등신. 팔다리가 짧아 구를 때 공처럼 보임 |
| 얼굴 | 아래로 처진 눈물방울 모양 검은 눈 무늬(순한 인상), 그 안에 아주 큰 반짝이는 눈, 작은 코, 발그레한 볼 |
| 컬러 | 털 흰색 `#F7F5F0` · 털 검정(부드러운 먹색) `#2E2B33` · 볼 분홍 `#F6A6B2` · 비니 빨강 `#E94F4F` |
| 시그니처 | **Panda Roll**: 공처럼 말아 앞구르기 후 두 팔 쫙. 렌즈에 볼 콩 |
| 표정 | 렌즈에 볼 눌린 얼굴, 함박웃음, 화면에 묻는 갸웃, 와! 놀람, 장난기 곁눈질, 신나서 소리치기 |
| 움직임 | 구를 때 완전히 공 모양. 멈추면 살짝 흔들리다 섬 |
| 목소리 | 작고 높은 남자아이 목소리 |
| 일관성 체크 | 빨간 비니는 구를 때도 벗겨지지 않음. 가족 중 항상 가장 작게. 검정은 새까맣지 않은 부드러운 먹색 |

## Mommy Panda

> 리본을 날리며 빙글빙글 도는 우아한 엄마.

| 항목 | 설정 |
|---|---|
| 성격 | 다정하고 우아함. 가족 율동의 리더 |
| 형태 언어 | 부드러운 S자 곡선의 서양배 모양 |
| 비율 | 3등신. 가족 중 가장 날씬 |
| 얼굴 | 긴 속눈썹, 눈 무늬가 살짝 위로 올라간 눈물방울, 부드러운 미소 |
| 컬러 | 털 흰색 `#F7F5F0` · 털 먹색 `#2E2B33` · 리본 분홍 `#F49AC1` |
| 시그니처 | 리본을 휘날리는 두 바퀴 빙글 |
| 표정 | 우아한 미소, 빙글 돌며 눈 감은 행복, 놀란 Wow |
| 움직임 | 발끝으로 사뿐사뿐. 회전할 때 리본이 늦게 따라옴 |
| 목소리 | 따뜻하고 노래하는 듯한 여성 목소리 |
| 일관성 체크 | 분홍 리본은 항상 한쪽 귀에. Daddy보다 작고 Grandma보다 크게 |

## Daddy Panda

> 배를 북처럼 두드리는 흥 많은 아빠.

| 항목 | 설정 |
|---|---|
| 성격 | 유쾌하고 장난기 많음. 큰 덩치로 몸개그 |
| 형태 언어 | 큰 원 두 개(머리 + 배). 넓고 묵직 |
| 비율 | 3.5등신. 가족 중 가장 큼 |
| 얼굴 | 웃을 때 눈이 초승달로 감김, 큰 입, 통통한 볼 |
| 컬러 | 털 흰색 `#F7F5F0` · 털 먹색 `#2E2B33` · 밀짚모자 노랑 `#E9C46A` |
| 시그니처 | 배 북 둥둥 3번, 마지막에 밀짚모자가 통 튀어 오름 |
| 표정 | 눈 감고 크게 웃기, 박자 타는 자신만만, 놀란 Wow |
| 움직임 | 묵직하게 쿵쿵, 배가 출렁 |
| 목소리 | 낮고 굵은 유쾌한 목소리 |
| 일관성 체크 | 노란 밀짚모자 항상 유지. 가족 중 항상 가장 크게 |

## Grandma Panda

> 느릿느릿하다가 갑자기 초고속 스핀을 선보이는 반전 할머니.

| 항목 | 설정 |
|---|---|
| 성격 | 느긋하고 다정하지만 숨은 실력자. 입버릇 "Oh my!" |
| 형태 언어 | 작은 원 + 살짝 굽은 등 |
| 비율 | 2.5등신. Bao보다 크고 Mommy보다 작음 |
| 얼굴 | 동그란 보라 안경 너머 작은 눈, 눈가 주름, 머리 위 회색 털 몇 가닥 |
| 컬러 | 털 흰색 `#F7F5F0` · 털 먹색 `#2E2B33` · 안경 보라 `#8C6BC8` · 숄 라벤더 `#C7B7E8` |
| 시그니처 | 느린 기지개 4번 → 갑자기 토네이도 스핀 |
| 표정 | 인자한 미소, 기지개 켜며 눈 감음, 스핀 후 뿌듯한 "Oh my!" |
| 움직임 | 평소엔 아주 느리게, 스핀만 번개처럼 빠르게(대비가 개그) |
| 목소리 | 따뜻하고 살짝 떨리는 할머니 목소리 |
| 일관성 체크 | 보라 안경과 라벤더 숄 항상 유지. 회색 털 몇 가닥 |
