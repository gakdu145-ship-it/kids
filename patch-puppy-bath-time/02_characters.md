# Patch the Puppy's Bath Time — 캐릭터 디자인

공통 스타일은 저장소 루트의 `STYLE_GUIDE.md`를 따릅니다.

**캐릭터 선정 근거:** 미취학 1위 IP Bluey, PAW Patrol 모두 강아지. 단, Bluey(파란 힐러견)와 겹치지 않게 크림색 털 + 한쪽 눈 갈색 반점으로 차별화.

**키 비교:** Quackers 0.2 : Patch 1 : Daddy Dog 2.6

## Patch

> 목욕은 싫지만 거품은 좋아하는 아기 강아지. 한쪽 눈 갈색 반점이 트레이드마크.

| 항목 | 설정 |
|---|---|
| 성격 | 장난꾸러기, 금방 마음이 바뀜. 싫다더니 제일 신나게 놂 |
| 형태 언어 | 원(머리) + 콩 모양 몸통. 귀만 길게 늘어진 물방울 모양 |
| 비율 | 1.8등신. 머리가 몸통과 거의 같은 크기, 짧고 통통한 다리 |
| 얼굴 | 오른쪽 눈을 감싸는 큰 캐러멜 반점 + 왼쪽 눈 위 작은 점(실루엣 포인트). 큰 갈색 눈(홍채 크게, 하이라이트 2개), 작고 까만 단추 코, 웃을 때 혀 끝이 살짝 |
| 컬러 | 털 크림 `#F5E6CC` · 반점·귀 캐러멜 `#C98A4B` · 눈 갈색 `#5A3A22` · 목걸이 빨강 `#E5484D` · 뼈다귀 태그 금색 `#E9B949` |
| 시그니처 | **Shake Shake**: 머리부터 꼬리까지 부르르 털기, 귀가 펄럭이며 물방울(또는 진흙)이 사방으로 |
| 표정 | "No way!" 고개 돌리기, 거품 보고 호기심, 간지러워 발라당 웃음, 화면에 묻는 갸웃, 거품 귀 쓴 뿌듯함, 장난기 곁눈질 |
| 움직임 | 꼬리는 기분 따라 속도 변화. 털 때 몸이 출렁이며 squash & stretch |
| 목소리 | 밝은 남자아이 목소리, 기분 좋으면 "Woof!" |
| 일관성 체크 | 큰 반점은 항상 오른쪽 눈(화면에서 보면 왼쪽), 꼬리 끝은 캐러멜색. 빨간 목걸이와 금색 뼈다귀 태그 유지. 털이 파랗거나 회색으로 바뀌지 않게 |

## Daddy Dog

> 털이 북슬북슬한 큰 아빠 강아지. 물벼락을 맞아도 허허.

| 항목 | 설정 |
|---|---|
| 성격 | 다정하고 느긋함. 아이 장난에 같이 웃어 줌 |
| 형태 언어 | 둥근 사각형(안정감). 넓은 가슴과 풍성한 털 |
| 비율 | 3등신. Patch의 약 2.6배 키 |
| 얼굴 | 졸린 듯 반쯤 내려온 따뜻한 눈, 큰 검은 코, 웃을 때 볼이 올라감 |
| 컬러 | 털 골든 `#E2B25C` · 코 검정(먹색) `#2E2B33` · 앞치마 노랑 `#FFD23F` |
| 시그니처 | 물뿌리개 샤워기로 빗물처럼 헹궈 주기. Patch가 털면 물벼락 |
| 표정 | 허허 웃음, 흐뭇한 미소, 물벼락 맞고 놀란 얼굴 |
| 움직임 | 느리고 묵직하게. 꼬리를 크게 천천히 흔듦 |
| 목소리 | 낮고 둥근 아빠 목소리 |
| 일관성 체크 | 노란 앞치마(허리에 묶는 천 앞치마) 항상 유지. Patch보다 확실히 크게 |

## Quackers

> 목욕 시간 진행자를 자처하는 고무 오리. 말할 때마다 삑!

| 항목 | 설정 |
|---|---|
| 성격 | 수다스럽고 밝음. 모든 말 앞에 "Squeak!" |
| 형태 언어 | 원(몸통) + 작은 삼각형(부리) |
| 비율 | 손바닥 크기. Patch 키의 약 1/5 |
| 얼굴 | 몸에 비해 아주 큰 눈, 눈썹으로 감정 표현, 부리가 입처럼 열림 |
| 컬러 | 몸통 노랑 `#FFD23F` · 부리 주황 `#FF8C2B` |
| 시그니처 | 물 위에서 통통 튀며 박자 맞추기 |
| 표정 | 신난 삑!, 박자 타는 윙크 |
| 움직임 | 물 위에서 위아래로 통통 |
| 목소리 | 높고 삑삑거리는 목소리 |
| 일관성 체크 | 고무 질감과 광택 유지. 팔 없음. 장면에 오리는 하나만 |
