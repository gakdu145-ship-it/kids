# Google Flow 장면 프롬프트 (처음부터 전체 생성)

설정: Veo 3.1 Lite, 9:16, x1, Ingredients to Video. 프롬프트는 수정 없이 그대로 붙여넣습니다.

## 0. 재료 이미지 준비

`ref-images/ingredient_*.png`를 재료로 올립니다. 원본 시트(`patch.jpg` 등)는 올리지 않습니다.

| 재료 | 만든 방법 | 이유 |
|---|---|---|
| `ingredient_patch.png` | `patch.jpg` 턴어라운드에서 정면 1컷만 잘라냄 | 4방향 시트를 그대로 올리면 같은 캐릭터가 여러 마리 나오는 쌍둥이 현상이 잘 생김 |
| `ingredient_daddy_dog.png` | `daddy_dog.jpg` 정면 1컷 | 위와 같음 |
| `ingredient_quackers.png` | `quackers.jpg` 정면 1컷 | 재료 칸이 남을 때만 사용 |
| `ingredient_bathroom.png` | `bathroom.jpg` 오른쪽 아래 Gemini 워터마크 제거 | 워터마크가 영상에 따라 나오는 것 방지 |
| `ingredient_backyard.png` | `backyard.jpg` 워터마크 제거 | 위와 같음 |

Flow 재료는 장면당 3장까지라 욕실 장면은 **patch + daddy_dog + bathroom**으로 고정합니다. Quackers는 프롬프트 설명만으로 그립니다(평범한 노란 고무 오리라 설명으로 충분).

**욕실 스타일 주의:** `bathroom.jpg`만 거의 실사풍(반사되는 금속, 사진 같은 타일)이고 캐릭터는 부드러운 그림책 톤입니다. 프롬프트에 "not photorealistic"을 넣어 두었지만, scene3 시험 생성에서 캐릭터가 붙여 넣은 것처럼 겉돌면 `node generate-images.mjs bathroom`으로 욕실만 다시 만듭니다. `bathroom.txt`에 지금과 같은 배치(왼쪽 수건걸이, 욕조 왼쪽 끝 위 물뿌리개, 오른쪽 위 둥근 창, 욕조 왼쪽 앞 파란 매트)를 고정해 두어서 장면 프롬프트를 고칠 필요는 없습니다. 새로 만든 뒤에도 워터마크는 지우고 올립니다.

## 1차 생성(scene1, scene2)에서 배운 것

| 문제 | 원인 | 바꾼 것 |
|---|---|---|
| scene2 시작에 실사 골든리트리버가 욕조에 앉아 있다가 사라지고, 앞치마 입은 아빠가 따로 들어옴 (아빠 2명) | 프롬프트의 "golden-retriever" 단어 | 견종 이름 삭제, "cartoon father dog character"로 쓰고 "No real animals, no other dogs" 추가. 시작할 때 욕조가 비어 있다고 명시 |
| Quackers가 Patch보다 큰 거대 오리로 바닥 거품 위에 나옴 | "smaller than Patch's head"가 약했고, 거품에서 튀어나오는 동작이 바닥 거품을 만듦 | "as small as Patch's paw, floating inside the tub", 튀어나오기 대신 욕조 안에서 통통. 거품은 욕조 안에만 |
| Patch가 욕조에 안 들어가고 바닥 매트에 앉아서 끝남 | 동작 4개(오리 등장·엿보기·꼬리·들어 올리기)가 한 문단에 섞여 있어 순서와 마지막 결과가 흐려짐 | 동작을 `[00:00-00:02]` 시간 구간으로 나누고, 마지막 구간에 "욕조 안에 앉아 배까지 거품"이라는 끝 상태를 명시 |
| scene1에서 진흙 덩어리가 공중에 멈춘 채 5초 넘게 떠 있음 | "렌즈에 진흙이 붙음"을 공중에 뜬 덩어리로 그림 | 렌즈 진흙은 편집에서 오버레이로 넣음(아래 편집 체크). 진흙은 잔디로 떨어지게 함 |
| scene1 첫·마지막 프레임에서 눈 반점이 진한 갈색 원판이 되어 눈이 가려짐 | 진흙이 몸 전체에 묻는다는 설명 | 진흙은 몸·다리·귀에만, 얼굴은 깨끗하고 두 눈이 보이게, 반점은 연한 캐러멜 |
| scene1이 꿀꿀 돼지 소리로 시작함 | 첫 2초에 정해진 목소리가 없었고, "chubby·mud·볼 부풀리기·코 치켜들기"가 돼지를 연상시킴 | 첫 프레임부터 Patch가 "Brrrrr!"라고 외치며 털기, "puppy dog" 명시, chubby·콧소리 동작 삭제, 들릴 목소리를 Patch 목소리와 작은 멍 소리로 한정 (scene8도 같이 수정) |
| scene1 후반 5초가 같은 자세로 정지 | 동작이 털기 하나뿐 | 고개 돌려 삐침 → 한쪽 눈으로 빼꼼 동작 추가 |

같은 원인이 다른 장면에도 있어서 scene3~8도 같은 방식으로 짧게 다시 썼습니다.

**그래도 욕실 장면이 계속 틀어지면:** Gemini에서 재료 3장(patch, daddy_dog, bathroom)을 넣어 그 장면의 첫 장면 이미지를 먼저 만들고, Flow의 Frames to Video에 시작 프레임으로 넣은 뒤 같은 프롬프트를 씁니다. 배치와 크기가 첫 프레임에서 고정되어 훨씬 안정적입니다.

## 욕실 장면 위치 (scene2~7 공통)

장면이 바뀌어도 좌우가 뒤집히지 않도록 모든 프롬프트에 같은 배치를 적었습니다.

- 아빠: 화면 왼쪽, 욕조 왼쪽 끝 앞 파란 매트에 무릎 꿇음 (scene7만 서 있음)
- Patch: 욕조 가운데, 카메라를 봄. 물은 배까지만 와서 머리·목걸이·앞발이 항상 보임
- Quackers: 화면 오른쪽
- 물뿌리개 샤워기: 욕조 왼쪽 끝 위. 그래서 scene6에서 Patch가 욕조 왼쪽 끝으로 가서 헹굽니다

## 배경음악 (`output/main_short_v5_music.mp4`, 최종 후보)

v4에 Mixkit "Jumping Around"(약 108 BPM, 보컬 없음)를 깐 버전입니다. 설정은 `sfx/cues.json`의 `music` 항목입니다.

- 기본 음량 `gain` 0.1(약 -34.5 dB). 대사·노래가 나오면 `duck` 0.6(-4.4 dB)까지 내려갔다가 0.4초에 걸쳐 돌아옵니다.
- Veo 소리는 약 75%가 목소리라 깊게 줄이면 음악이 거의 안 들립니다. 그래서 얕게 줄입니다.

- 다른 곡으로 바꾸려면 `music/`에 WAV를 넣고 `file`만 바꾼 뒤 `sfx/mix-sfx.ps1`을 실행합니다.

## 최종: `output/main_short_v6.mp4`

v5에서 바뀐 점:
- 배경음악 `gain` 0.1 → 0.2 (+6 dB). v5는 음악이 거의 안 들렸음.
- 마스터링 추가(`cues.json`의 `master`): Veo 원본 소리가 평균 -27 dB로 작아서 전체를 -18 dB까지 올리고(+9.4 dB), 리미터로 피크를 -1 dBFS 아래로 잡음. YouTube는 큰 소리만 줄이고 작은 소리는 키워 주지 않음.
- 렌즈 진흙 화면 효과(`cues.json`의 `overlays`, 그림은 `fx/make-splats.ps1`): 1.00·1.18·1.28초에 진흙 3개가 살짝 커졌다 붙고, 아래로 흘러내리다 2.6~2.9초에 사라짐. 3.0초 "Bath time?" 전에 다 없어져서 얼굴을 가리지 않음. 위치·크기·시간은 `x`, `y`, `w`, `from`, `to`로 조절.

## 편집 체크

- **배경 음악은 편집에서 한 곡으로 깝니다.** 모든 프롬프트에 "no background music"을 넣었습니다. Veo가 장면마다 다른 음악을 만들면 컷마다 음악이 끊겨 노래 영상처럼 들리지 않습니다. 대사·노래·효과음만 Veo 소리를 쓰고, 그 아래 같은 템포의 밝은 반주 한 곡을 처음부터 끝까지 깝니다.
- scene1의 첫 프레임이 곧 훅입니다. 앞을 자르지 말고, 첫 1초 안에 털기 소리가 시작되는지 확인합니다.
- **렌즈에 진흙 촥:** scene1 털기 순간(약 1초)에 편집 앱의 진흙/물방울 스플래시 오버레이와 "splat" 효과음을 얹고, 1~2초 뒤 흘러내리듯 사라지게 합니다. Veo에 맡기면 진흙 덩어리가 공중에 멈춰 떠 있습니다.
- **루프:** scene8은 진흙 묻은 Patch가 카메라 앞에 멈춰 서서 털기 직전에 끝납니다. 이 마지막 프레임이 scene1 첫 프레임(같은 로우 앵글 클로즈업)과 같은 그림이라, 다시 재생되면 scene1의 털기와 렌즈 진흙이 이어집니다. 털기가 두 번 나오지 않도록 scene8 끝에 털기가 생겼다면 털기 직전에서 자릅니다. 페이드나 엔드카드는 넣지 않습니다.
- 클립 오른쪽 아래의 작은 "Veo" 표시는 Flow가 넣는 것이라 프롬프트로는 없앨 수 없습니다. 업로드 전에 확인하세요.
- 질문 대사 뒤("Where's your tummy?")는 0.5~1초 여유를 남겨 아이가 따라 할 틈을 줍니다.
- 클립 끝 0.2초쯤 소리가 툭 끊기면 오디오를 짧게 페이드아웃합니다.

## 공통 규칙 (모든 프롬프트에 이미 들어 있음)

- 같은 마당/욕실 설명과 배경 재료로 장소 고정, 욕실은 배치까지 고정
- Camera / Setting / Characters / Action / Dialogue / Audio / Style 순서, 250~320단어. 동작은 `[00:00-00:02]` 시간 구간으로 2~3개만
- 대사는 `Dialogue:` 줄에 말하는 캐릭터와 목소리를 함께 적고, 대사가 없는 캐릭터는 "do not speak"로 막음
- 견종 이름(golden retriever 등) 금지. "cartoon dog character" + "No real animals, no other dogs"
- 고무 오리는 하나, Quackers는 Patch 발만 한 크기로 항상 욕조 안 또는 욕조 가장자리
- 욕실 장면(scene2~7)에는 항상 아빠 강아지가 곁에 있음 (아이 혼자 목욕 금지), 물은 배까지만
- Patch는 항상 오른쪽 눈 큰 캐러멜 반점 + 빨간 목걸이, 두 발로 섬. 진흙이 묻어도 얼굴·반점·목걸이는 보이게
- 캐릭터마다 한 명씩만 (no twins), 자막·글자·워터마크 금지
- 장면당 카메라 무브 1개, 속도와 시작·끝 구도 명시
