## 목표

애니메이션 1화의 지하철 만남 장면을 실사풍 AI 영상으로 옮겨 보며 아래를 연습합니다.

1. 원작 캐릭터를 실사 얼굴로 옮겨 장면마다 같은 얼굴로 유지하기
2. **소리 연출:** 유키가 입 모양을 못 읽으면 소리가 끊기고, 읽을 수 있으면 목소리가 들리는 원작 연출을 영상과 편집으로 재현하기
3. 대사보다 표정·손짓·시선으로 감정 전달하기

## 소리 연출 규칙 (지하철 시퀀스)

| 상황 | 화면 | 소리 |
|---|---|---|
| 관광객이 빠르게 영어로 말함 | 관광객 입이 빠르게 움직임, 유키 당황 | **완전한 무음** 또는 아주 먹먹한 저음. 지하철 소음도 끊김 |
| 이츠오미가 관광객과 영어로 대화 | 유키 시점에서 둘을 봄 | 무음 (유키는 못 읽음) |
| 이츠오미가 유키를 보며 천천히 말함 | 입 모양 클로즈업 | **그 순간부터 이츠오미 목소리만 또렷하게** 들림. 배경 소음은 여전히 없음 |
| 머리 쓰다듬기 | 손이 머리에 닿음 | 무음 위로 아주 작은 음악(편집) |

Veo에서는 모든 클립을 **소리 없이**(무대사·무음악) 생성하고, 소리는 편집에서 이 표대로 넣습니다. Veo가 만든 목소리를 끊었다 켰다 하는 것보다 처음부터 편집으로 설계하는 게 확실합니다.

## 진행 순서

1. 캐릭터 시트: `ref-images/yuki_sheet.txt`, `ref-images/itsuomi_sheet.txt` (직장인 시리즈와 같은 한국어 상세 형식)
2. 시트 이미지가 원작과 닮게 나오는지 확인하고 다듬기
3. 지하철 객차 배경 레퍼런스
4. 2~5번 장면 클립 프롬프트 (소리 없이)
5. 편집에서 소리 연출

## 확인 필요

원작 캐릭터의 세부 외모(머리 길이·색, 옷, 액세서리)는 제 기억과 리뷰 요약을 바탕으로 썼습니다. **원작을 보면서 다른 부분을 알려 주세요.** 시트가 원작과 맞아야 실사화 연습이 의미가 있습니다.
